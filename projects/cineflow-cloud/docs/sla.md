# 五分钟硬 SLA

## 精确定义

“5 分钟视频最多 5 分钟处理完成”定义为：

- 输入视频已经完成 OSS 上传；
- `POST /v1/jobs` 返回 202 的时刻开始计时；
- 输入时长不超过 300 秒、1080p、单目标语言；
- 任务已通过 p95 运行时间和实时容量准入；
- 300 秒内产生成功成片或明确的终态；
- 上传时间不在 SLA 内，因为公网带宽不受服务端控制。

## 为何会拒绝任务

硬 SLA 不能靠“先接单再排队”。以下情况在产生付费调用前拒绝：

- 所有预热槽位已占用；
- 输入超过 5 分钟、512MB 或 1080p；
- 不支持的编码；
- 根据最近 p95 预测无法保留 20 秒安全余量；
- Worker 未预热或健康检查失败；
- 估算费用超过请求中的 `max_cost_cny`。

## 降级顺序

为了优先交付成片，非关键增强按以下顺序降级：

1. 多模态人物识别超时：退化为单个 Azure 默认声音，并标记待复核；
2. 去硬字幕或声伴分离超时：保留原画面/原背景；
3. Azure 主区域故障：切换第二 Azure 区域；
4. ASR 主 Worker 故障：生产部署应配置第二 ASR Worker。

翻译、TTS 和最终合成没有可用结果时，任务失败而不是伪造成成功。上线前必须用真实素材证明预热容量下的 p95 小于 280 秒。

## 初始阶段截止点

| 阶段 | 截止点（任务开始后） |
|---|---:|
| ASR | 60 秒 |
| 媒体增强 | 130 秒 |
| 多模态人物 + 翻译 | 170 秒 |
| Azure TTS | 245 秒 |
| 合成 | 290 秒 |
| 状态落盘/响应余量 | 10 秒 |

## 费用硬门禁

准入阶段同时计算预计费用。默认五分钟任务预算为 5 元，可由请求的 `max_cost_cny` 下调或上调。估算包含 ASR、DeepSeek、Azure TTS、多模态 GPU、视频合成、可选声伴分离和可选字幕消除。

该估算用于阻止明显超预算任务，不替代云厂商账单。生产环境应在每个 Provider 响应后回写实际字符数、音频秒数、GPU 活跃秒数和转码分钟数。

## 健康与预热

提交任务前会调用 Media、ASR 和 Speaker Worker 的 `/healthz`。严格 SLA 要求：

- `healthy=true`；
- `warm=true`；
- 存在立即执行槽位；
- p95 预测不超过 280 秒；
- 费用预测不超过任务预算。

任一条件不满足时不产生付费调用。
