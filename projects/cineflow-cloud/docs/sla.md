# 五分钟性能目标

## 定义

对于输入时长不超过 300 秒的视频，CineFlow 的目标是尽可能在视频上传完成并正式创建处理任务后的 300 秒内交付成片。

这不是硬 SLA，也不是强制超时：

- 预测超过 300 秒仍可接收；
- 没有空闲槽位时进入队列；
- Worker 未预热会产生警告，但不会仅因此拒绝；
- 运行到 300 秒不会取消 Provider 请求；
- 超过目标后继续执行，直到成功、降级成功或真实失败；
- 最终通过 `target_exceeded` 记录是否达到目标。

## 上传时间如何统计

新项目已经包含 STS、OSS multipart、并发上传和断点续传，但用户公网带宽无法由服务端保证。因此：

```text
upload_elapsed_seconds       单独统计上传耗时
processing_elapsed_seconds   从翻译处理任务接受后统计
```

字幕消除是完整流程的一部分。产品应同时展示：

```text
上传耗时
字幕消除耗时
翻译配音流水线耗时
端到端总耗时
```

主要的“5 分钟视频尽量 5 分钟完成”优化指标针对服务端字幕消除与翻译配音流水线；上传耗时单列，不能通过隐藏上传等待来制造虚假的达标率。

## 哪些情况会拒绝

拒绝只用于无法正常执行或明显违反约束的任务：

- 视频超过当前产品允许的 5 分钟；
- 文件超过上传 Worker 配置上限；
- 上传对象大小或 SHA-256 校验失败；
- 字幕消除指定的 provider 未配置；
- 翻译流水线必需 Provider 没有任何健康路径；
- 预计费用超过用户授权预算；
- 请求参数不合法。

“预计会慢”“当前槽位繁忙”“Worker 是冷的”都不构成拒绝理由。

## 阶段目标

下列检查点用于监控和优化，不触发取消：

| 阶段 | 初始优化目标 |
|---|---:|
| 已上传对象校验 | 5 秒 |
| 字幕消除提交 | 10 秒内得到外部 JobId |
| ASR | 60 秒 |
| Media 准备 | 130 秒 |
| 多模态人物 + DeepSeek 翻译 | 170 秒 |
| Azure TTS | 245 秒 |
| 最终合成 | 290 秒 |
| 服务端整体 | 300 秒 |

字幕消除的真正完成时间取决于 provider。其提交时间、厂商排队、处理时间、结果复制和验证应分别记录。阶段超过检查点时发送性能告警，任务继续运行。

## 并发与排队

翻译控制平面的 `max_inflight_jobs` 控制同时运行数。额外任务进入队列并暴露：

```json
{
  "inflight": 2,
  "queued": 1,
  "max_inflight": 2,
  "available": 0
}
```

Upload、Subtitle、Media、ASR、Speaker 和 Azure TTS 各自还有并发限制。系统的实际吞吐由最慢阶段决定，不能只提高控制平面并发。

当前 MVP：

- Upload/Subtitle 使用文件状态和持久卷；
- 控制平面任务与事件仍为进程内；
- 多副本上线前迁移到 PostgreSQL/Redis 和分布式锁。

## Provider 健康和恢复

- 必需 provider 无首选也无后备：拒绝；
- `healthy=true, warm=false`：接受并警告可能错过目标；
- 首选 ASR 失败：调用火山后备；
- Subtitle `provider=auto`：选择第一个已配置的 Alibaba/Caca/local 后端；
- Subtitle 指定 provider：不可用时不静默切换；
- Upload session、multipart upload ID 和 Subtitle 外部 JobId 会持久化；
- Worker 重启后可以恢复上传会话和云字幕任务；
- 本地字幕模型任务中断后重新执行，不伪造内部断点。

## 费用门禁

费用预算仍是硬门禁，因为它代表用户授权。

完整预算应包含：

- OSS 存储和流量；
- 字幕消除 provider；
- ASR；
- DeepSeek 翻译；
- Azure TTS，包括时长拟合重试；
- 多模态 GPU；
- MusicDemix；
- 最终合成；
- 失败后已实际发生的厂商费用。

当前控制平面的报价模型主要覆盖 ASR、翻译、TTS、GPU、声伴分离和合成。Upload 与 Subtitle Worker 已输出会话、provider 和处理元数据，但仍需接入统一实际账单表，才能把所有步骤汇总到同一个任务成本。

## 降级原则

可以降级但必须明确标记：

- 多模态人物失败：退为单音色或低置信度人工复核；
- MusicDemix 失败：保留原背景或仅使用可用音频；
- Azure 达到最大语速仍超时：保留完整台词，记录 `timing_warning`；
- 字幕消除输出有轻微非关键告警：`degraded`；
- 输出时长、画面或对象校验严重失败：任务失败并清理无效输出。

不得通过裁掉台词、丢弃有效云任务、超过 300 秒强制失败或伪造成功来提高达标率。

## 上线验收

至少按 30 秒、2 分钟、5 分钟素材统计：

- 上传 p50/p90/p95；
- 字幕消除 p50/p90/p95；
- 翻译流水线 p50/p90/p95；
- 端到端 p50/p90/p95；
- 300 秒内完成率；
- `target_exceeded` 比例；
- 上传恢复成功率；
- 字幕任务恢复成功率；
- 人物归因准确率；
- Azure 二次生成率和残余超时率；
- 单任务预计成本与实际成本偏差；
- provider 首选到后备切换率。

第一阶段目标是提高真实 300 秒内成功率，而不是通过拒单或强制超时制造虚假的指标。
