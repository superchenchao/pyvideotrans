# 云端字幕消除

pyVideoTrans 保留原有的本地 STTN / ProPainter，并增加两个用户主动选择的云端后端：

- `Caca API（OSS 链接）`：上传到私有阿里云 OSS 后，向接口提交一条有时效的签名 HTTPS 地址。
- `阿里云 IMS`：上传到同地域私有 OSS，使用 `VideoDetext` 异步任务处理。

本地模型仍是默认选项。切换后端不会覆盖或删除其他后端的结果缓存。

## 上传文件标准

云端后端不会上传源视频，而是直接从源文件生成一份传输视频：

- MP4 / H.264
- 横屏 1920×1080，竖屏 1080×1920
- 25 FPS CFR
- 约 6000 kbps
- 不包含音频

OSS 使用私有 Bucket、断点续传、稳定对象路径、上传后对象大小校验。上传和下载的分片并发默认为 8，可在云端字幕消除设置中调整为 1～16，连接池会自动保持比并发数多 2。小于 32 MB 的文件由 SDK 直接传输。链接 API 得到的是临时签名 URL，不需要把 Bucket 改成公共读。

## 凭据

密钥只从环境变量读取，不写入普通设置、任务 JSON 或日志。Windows 可在“系统属性 → 环境变量”中添加后重启 pyVideoTrans。

OSS 与 IMS：

```text
OSS_ACCESS_KEY_ID
OSS_ACCESS_KEY_SECRET
```

也支持阿里云标准名称：

```text
ALIBABA_CLOUD_ACCESS_KEY_ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET
```

使用 STS 时可增加 `OSS_SESSION_TOKEN` 或 `ALIBABA_CLOUD_SECURITY_TOKEN`。

Caca API：

```text
PYVIDEOTRANS_CACA_SECRET_ID
PYVIDEOTRANS_CACA_SECRET_KEY
```

请使用专用 RAM 用户和最小权限，不要使用阿里云主账号 AccessKey。

## 使用

1. 勾选“消除原视频字幕”。
2. 在旁边选择“本地模型”“Caca API（OSS 链接）”或“阿里云 IMS”。
3. 云端方式点击“云端设置”，填写 OSS 地域、Bucket 等非敏感配置。
4. 开始任务并框选字幕区域。

云端字幕任务并发可在同一设置窗口中分别调整：

- 阿里云 IMS 默认同时处理 5 个任务。
- Caca API 默认同时处理 8 个任务。
- 两者都可设置为 1～16，保存后需要重启 pyVideoTrans 才会重建对应工作线程。
- 该设置只影响云端字幕任务，不改变本地 STTN / ProPainter 的 GPU 并发。
- 如果“每批处理数量”小于云端并发，实际同时运行数仍以当前批次视频数为上限。

多文件夹、多语言任务中心采用按单集释放的流水线：

- IMS / Caca 预处理与 GPU 识别使用两个独立并发池。云端任务完成后进入识别等待队列，不会占住云端任务槽位，因此后续集数仍可继续上传和提交。
- 某一集完成 IMS / Caca、识别并通过原文审核后，该集所有目标语言立即进入翻译队列，不等待其他集。
- 某个语言完成译文、角色或配音审核后，会独立进入下一阶段，不等待同集或其他集的其他语言。
- 流水推进仍遵守全局上限：云端字幕、GPU 识别、翻译、配音、对齐和合成分别使用各自的并发数，不会因提前放行而无限创建实际工作任务。
- 调度器优先排空更靠近成品的合成、对齐和配音任务。下游积压达到安全水位时，上游会暂缓投放；内存可用量低于 4 GB 或使用率达到 92% 时，也会暂停新增预处理、识别和翻译，但不会阻止已有下游任务收尾。
- 任务中心实时显示每个阶段的“运行数 / 并发上限 / 等待数”，并明确标注因下游积压或内存保护造成的暂停。
- “本阶段全部跳过”会立即释放该语言当前阶段已经等待的任务，后续新到达的同阶段任务也会直接通过。

GPU 识别并发继续读取“更多设置 → GPU 同时任务数”。它是安全上限，不会因为 IMS 配置为 5 就自动增加。单张显卡是否适合设为 2，仍应以显存余量和实际视频测试为准；调度器会尽量填满用户配置的上限，但不会为了追求利用率突破该上限。

默认开启“本地完整校验后删除 OSS 输入/输出临时文件”：

- 阿里云 IMS 在本地结果验证并写入缓存后，删除 OSS 输入和输出。
- Caca API 删除 OSS 输入；接口方返回的结果位于其服务器，因接口未提供删除能力，程序无法代为删除。
- 删除失败不会丢失本地成品，状态会保留为 `cleanup_pending`，下次复用本地缓存时继续清理。

链接 API 的坐标单位在接口文档中没有明确说明，因此默认让接口自动检测。只有接口提供方确认接受 0～1 归一化坐标后，才启用“发送归一化 x1/y1/x2/y2”。

## 失败恢复

- OSS 上传和下载均使用断点续传。
- 取得远端任务 ID 后立即持久化；软件重启后继续查询，不重复提交。
- 提交请求超时且无法确认是否已创建任务时，状态标记为 `submit_unknown`，程序不会自动重提，避免重复计费。
- 下载到临时文件后检查大小；云端结果还会校验分辨率、帧率、时长并完整解码，再写入可复用缓存。
- 用户取消时保留任务 ID。链接 API 没有取消接口，下一次可继续查询；IMS 会尽力请求远端取消。
- 自动清理只发生在本地文件完整解码且缓存元数据写入成功之后。

任务状态文件和下载临时文件都在当前视频缓存目录。选择“清理已生成”会清除这些恢复信息，因此远端任务运行期间不要清理缓存。
